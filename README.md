# NeuroAccess Monorepo

This repository is organized by team ownership.

## Top-level folders
- frontend/chrome-extension: browser extension app (active code)
- backend/api: backend APIs
- ai/services: AI microservices
- shared: contracts and schemas shared across teams
- infra: CI/CD and deployment assets
- docs: architecture, legal, and project docs

## Current frontend commands
Run from frontend/chrome-extension:

- npm run build
- npm run dev
- npm run lint
- npm test
